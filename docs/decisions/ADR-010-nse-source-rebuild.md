# ADR 010 NSE source rebuild and explicit execution charges

Status: Accepted experimental implementation scope, 2026-10-18, under the user's
instruction to complete the audited repairs. Extends ADR 009; v1 remains immutable.

Create a new retrospective Jan2025–June2026 minute snapshot from hashed public
responses. Reverse the documented 2025/2026 Nifty reviews from the current roster;
retain temporary ITCHOTELS, TMCV and KWIL membership separately from listing and
tradability. Unlisted dummy index values are never execution prices. Historical
membership reconstructed using later official evidence is not a contemporaneously
captured constituent feed. Retain announcement/effective dates and source notices.

Recover both full Budget sessions and the 60-minute Muhurat session from raw
responses. Features reset at session/gap boundaries and use the actual session
opening for slot numbers. Replay uses the scheduled final opening to flatten.
Retrospective completeness is a conditional cohort, not a causal outage policy.

Preserve provider prices and volumes. Do not manufacture historical raw prices
from rounded adjusted prices. Quarantine known split/bonus/demerger/rights
histories and any identity/reference failures. Compare every available stock-day
against official daily extremes using a fixed 0.2% scale screen; passing this
screen is not certification of individual minute prices, volume or adjustments.
Missing official files and unavailable public history remain explicit exclusions.
No new research may silently fall back to the v1 current-company snapshot.

The opt-in `nse_minute_research_v2` uses a dated statutory charge estimate and
current public Zerodha brokerage scenario: order-level cap, side-aware stamp,
exchange/IPFT, SEBI and GST. Reserve sell-notional STT causally during replay;
settle to the security/day VWAP and client-day rounding at the flat session end
using a separate auditable signed fee adjustment. No fictitious settlement fill.
Stress multiplies charges and slippage independently by the recorded multiplier.
The v1 flat proxy and all crypto paths remain unchanged. Historical brokerage,
observed slippage/liquidity and contract-note acceptance are still assumptions.

Use the same fixed TRAIN fit/calibration dates and model parameters as ADR009.
Use a fixed 21-bps ML entry hurdle approximating reference charges plus 5bps/side
slippage; this is a preregistered scenario, not a bound on small-order billing.
Preregister a new cohort/run only after its inputs pass the explicit conditional
screen. Never use VALID results to tune source thresholds or model parameters.
TEST stays sealed and G7 remains false. This repair alone does not authorize a
promoted candidate, live orders, or an elapsed PAPER-trial claim.
